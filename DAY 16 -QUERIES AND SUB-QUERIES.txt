DAY 16 -QUERIES AND SUB-QUERIES

WHAT IS SUB-QUERY?
-------------------
A sub-query is a query inside another query.
it is written inside parenthesis. And its result is used by the outer query

it is also called as :-
inner query
nested query or 
inner select

general syntax:- 
select column-list 
from table
where column OPERATOR(select column from table where condition)

purpose of sub-query?
to breakdown complex into smaller queries
to use the result of one query as input of another query
to avoid multiple steps(write in a single query instead of temporary queries)

types:-
---------
single-row subquery
multi-row subquery
nested subquery
corelated subquery
exists/not exists subquery

1.single-row subquery
---------------------
single row subqueries returns exactly one row and one column. they use comparison operators(<,>,<=,>=)

characteristics:-
they return only one value
can use single-value comparison operators
if subquery returns no rows or multiple rows, it causes error

syntax:-
select column
from table
where column operator(select column from table where condition)

2.multi-row subquery
---------------------
a) multi-row subqueries with IN,
it returns more than one row. the IN operator is used when you want to compare a value with multiple values,return by the subquery

characteristics:-
returns multiple rows
use the IN operator
checks is a value exists in the list returned by the subquery.
equivalent to multiple OR conditions 
most commonly used for matching values

syntax:-
select column
from table
where column IN(select column from table where condition)

b)multi-row subquery (ANY/SOME)
multi-row subqueries returns multiple rows .when using ANY or SOME ,if the condition is true if it matches at leastc)  one value retuned by the subquery

characteristics:-
returns multiple values
any and some are interchangeable
condition is true if any of the values satisfy the condition often usd with IN,>ANY ,<ANY,=ANY etc.

syntax:-
select column
from table
where column ANY/SOME(select column from table where condition)

c)Multi-row subquery (ALL):-
it means the conditions must be true for all the values returned by the subquery 

characteristics:-
condition must be true for all values in the subquery result
often used with >all,<all,>=all,<=all
>all means greater than the maximum value
<all means less than the minimum value 

syntax:-
select column
from table
where column ALL(select column from table where condition)

3.nested subquery
------------------
THESE ARE THE SUBQUERIES within subqueries. they can be multiple levels deep and are executed from the innermost to the outermost

characteristics :-
inner queries execute first,
can combine different types of subqueries useful for complex conditions 

syntax-
select column list
from table 
where column(select column
              from table 
               where column=(select column
                              from table     
                                 where condition));

4.corelated subquery:-
---------------------
these are the subqueries that reference column from the outer query. unlike regular subqueries the are execute once. corelated subqueries execute once for each proceed by the outer subquery  
 
characteristics:-
reference column from the outer query 
executes multiple times(once per outer row)
cannot be executed independently'
often used with exists ,not exists
generally slower than non-corelated subqueries.

syntax:-
select columns
from table1 outer_alias
where condition(select column
                  from table2 inner_alias
                    where inner_alias.column=outer_alias.column);

5.exists and not exists subqueries:-
-----------------------------------    
exists is used to test whether sub-query returns any rows.it returns true if the sub-query returns at least one row otherwise returns false. Not Exists returns true is the subquery returns no rows

characteristics:-
returns TRUE/FALSE 
more efficient than IN for large databases
often used with corelated subqueries 
stops execution as soon as first match is found
select clause is in Exists DOESNT matter

syntax:-
select columns from table 1
where exists (select 1 from table2 where condition);

syntax:- 
select column
from table
where not exists (select 1 from table2 where condition);
